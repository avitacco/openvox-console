# 2.9 - install script checks

The three scripts were fetched as a node would get them (`/packages/install.sh`, `/packages/install-macos.sh`,
`/packages/install.ps1`) from a console built from this change.

```
$ shellcheck -s bash install.sh install-macos.sh
install.sh:50,51  SC1091 (info): Not following: /etc/os-release was not specified as input
  (informational, and present before this change; nothing else reported)

$ shellcheck internal/agentdist/pkgassets/postinst.sh internal/agentdist/pkgassets/postrm.sh
  (clean)

$ docker run mcr.microsoft.com/powershell  -  pwsh 7.4.2, PSScriptAnalyzer 1.23.0
  [System.Management.Automation.Language.Parser]::ParseFile(install.ps1)   parse errors: 0
  Invoke-ScriptAnalyzer -Path install.ps1                                  findings: 11
    11 x PSAvoidUsingWriteHost, Warning
```

`PSAvoidUsingWriteHost` is the finding accepted in `add-multi-platform-agent-install` and `add-package-inventory-reporting`:
the script prints its progress for whoever runs it and is not pipeline code. No other rule fired.

PSScriptAnalyzer 1.23.0 rather than the current 1.25.0, which refuses to load on the image's pwsh 7.4.2.

The `sc.exe failure` line the script now carries, and the macOS job's unconditional `KeepAlive`:

```
& sc.exe failure $ServiceName reset= 86400 actions= restart/5000/restart/5000/restart/60000 | Out-Null
<key>KeepAlive</key>
<true/>
```

Both are asserted by `internal/agentdist/artifacts_test.go` and `handlers_test.go`, which pass.
