Root cause of the uneven-looking divider: any approach that grows an individual card's own box (vox-grid's 1fr columns, then per-card `flex-grow`) leaves the extra width trailing *after* that card's left-aligned text - so whichever card happens to sit right before the divider looks (dis)connected from it depending on that specific card's label length ("Unchanged" being short made the gap look large), independent of the actual CSS gap value. Fixed by giving every card its natural content width (no grow/basis override) and using `justify-content: space-between` on the row so leftover width becomes extra *gap* between items instead of extra width inside any one item's box - verified by measuring the rendered screenshot: ~121px between every adjacent card pair, including both sides of the divider, real counts (Connected: 1, Disconnected: 6) - see `evidence/dashboard-connectivity-cards.png`
