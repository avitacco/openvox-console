Nodes 分類 Code オーケストレーション セキュリティ アクセス制御 Scaling

Node グループは Nodes がすでに報告している Facts に基づいて一致し、openvox-server が期待する ENC 契約で答えを渡します。

実在の Nodes に一致するグループ

Facts からルールを組み立てると — os.family = Debian、role = web など — コンソールが今この時点で何件の Nodes に一致するかを示します。何にも当たらないルールは、次の Puppet run を待たずにその場で分かります。

ページ上で読み取れる優先順位

複数のグループが一つの Node に適用される場合、どれが優先されるかは一つの数値が決めます。グループはフラットで、それぞれが明示的な優先度を持つため、なぜその Node がそのクラスを得たのかを知るには、継承ツリーをたどるのではなく一覧を読むだけで済みます。

A node asks for its catalog openvox-server asks the console what applies Matching groups merge by priority Classes, parameters and environment come back

一度もチェックインしていない Node にはまだ Facts がないため、Fact ベースのルールは一致しません。初回実行の前に分類が必要なら、グループに直接固定してください。
