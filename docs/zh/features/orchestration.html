针对你挑选的 Nodes 触发 Puppet 运行、Tasks 和 Plans，并看着结果一个 Node 接一个 Node 地返回。

按 Node 而非按 Job 给出结果

每个目标都被单独记录：状态、退出码和输出。一个在九个 Nodes 上成功、在一个上失败的 Job 会如实呈现，而不会收敛成一个你之后还得去追查的单一结论。

当某个 Job 触发了 Puppet 运行时，其结果会直接链接到该次运行产生的 Report——于是「这究竟改变了什么」只需一次点击。

Targets recorded, each one pending. Work goes out to the nodes. Each node reports back as it finishes. The job takes the status its targets add up to.

编排基于 NATS 运行，因此覆盖大型机群只是增加容量的问题，而不必重做消息路由方式。

Do it

Run Puppet on demand on one node, a selection, or every node a group matches, and see what each node did.

OpenVox Console ships as container images, built for amd64 and arm64 on every push, and as a single binary. The install guides take you from an empty host to a working deployment - openvoxserver, openvoxdb, Postgres and the console - with containers or with packages.
