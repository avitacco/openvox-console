Nodes वर्गीकरण Code ऑर्केस्ट्रेशन सुरक्षा पहुँच नियंत्रण

अंतर्निहित g10k के साथ control रिपॉज़िटरी से Environments deploy कीजिए। माँग पर या सीधे किसी push से, हर deploy के रिकॉर्ड के साथ।

एक control रिपॉज़िटरी, या हर टीम के लिए एक

जो टीमें अपनी अलग control रिपॉज़िटरी रखती हैं, उन्हें अब एक साझा करने की ज़रूरत नहीं। हर एक को स्रोत के रूप में जोड़िए, और जिन्हें चाहिए उन्हें उपसर्ग दीजिए, ताकि production शाखा वाली दो रिपॉज़िटरी एक-दूसरे को अधिलेखित करने के बजाय अलग-अलग Environments में उतरें।

sources: control: remote: https://git.example.com/infra/control-repo.git prefix: false team_a: remote: https://git.example.com/team-a/control.git prefix: true

हर deploy एक निशान छोड़ता है

किसने चलाया, कौन-सा स्रोत और कौन-सी ref, कौन-सा Environment लिखा गया, और यह सफल रहा या नहीं। विफल deploy अपनी त्रुटि बनाए रखता है, सूची से चुपचाप ग़ायब नहीं होता।

हर रिपॉज़िटरी का अपना webhook और अपना गुप्त कुंजी-मान होता है, इसलिए एक से लीक हुआ रहस्य दूसरे को deploy करने के काम नहीं आ सकता।

Do it

Deploy Puppet code from one or more control repositories into the environments openvoxserver compiles from.

OpenVox Console ships as container images, built for amd64 and arm64 on every push, and as a single binary. The install guides take you from an empty host to a working deployment - openvoxserver, openvoxdb, Postgres and the console - with containers or with packages.
