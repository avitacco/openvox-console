Nodes التصنيف Code التنسيق تثبيت التصحيحات الأمان التحكم في الوصول وكلاء الذكاء الاصطناعي التوسّع

امسح Nodes الـ Linux بحثًا عن التحديثات الناقصة لديها، وطبّقها على دفعات مع وسيلة للتوقف قبل أن يصل تحديث سيئ إلى الأسطول بأكمله.

التحديثات المعلّقة، كما يُبلّغ عنها مدير الحزم في كل Node

يطلب المسح من وكيل الـ Node تشغيل apt أو dnf أو yum في وضع لا يغيّر شيئًا، ثم يعرض كل تحديث معلّق مع إصداريه المثبَّت والمتاح وما إذا كان مدير الحزم يعدّه تحديثًا أمنيًا. ويذكر الـ Node أيضًا ما إذا كان يحتاج بالفعل إلى إعادة تشغيل.

تجري عمليات المسح وفق جدول تتحكم فيه، أو عند الطلب لـ Node واحد أو لمجموعة كاملة. والـ Node الذي يتعذّر مسحه يُدرج على أنه غير قادر على الإبلاغ — ولا يُعرض أبدًا على أنه مُصحَّح بالكامل.

صحّح على دفعات، مع توقف آمن

اختر التحديثات الأمنية، أو كل شيء، أو حزمًا محددة بالاسم، وعدد الـ Nodes التي تُصحَّح في وقت واحد. وحدّد عدد حالات الفشل التي تُنهي التشغيل، كي لا تبدأ دفعة أخرى بعد أن يسوء شيء ما. وعاين بتشغيل تجريبي لا يثبّت شيئًا، ودع الـ Nodes التي تحتاج إلى إعادة التشغيل تُعيد تشغيلها حين تنتهي.

يُعرض التقدّم Node تلو Node، والـ Node الذي يصمت في منتصف الطريق يُبلَّغ عنه بذلك بدل أن يبقى معلّقًا إلى الأبد، وحين ينتهي يُمسح الـ Node مجددًا فتعرض الصفحة ما تبقّى فعلًا.

Each node reports what its package manager would upgrade. Preview a run on the nodes you chose. Nothing is installed. Patch a few nodes at a time, stopping after as many failures as you allow. Each patched node is scanned again, so what remains is on record. Scanning and patching follow the same node group access as every other action: people can patch the nodes their roles cover, and no others. Patch runs are jobs like any other, with results per node, and show up in the job history with their options.

لا تُمسح Nodes الـ Windows وmacOS وzypper ‏(SUSE). بل تُدرج على أنها غير قادرة على الإبلاغ، فتبقى الثغرة في التغطية ظاهرة بدل أن تُحسب خطأً شهادةً بالسلامة.

نفّذ ذلك

امسح Nodes الـ Linux بحثًا عن تحديثات الحزم المعلّقة، ثم صحّحها على دفعات مع تشغيل تجريبي، وحدّ للتوقف، وإعادة تشغيل اختيارية.

يُوزَّع OpenVox Console على هيئة صور حاويات تُبنى لمعماريتَي amd64 وarm64 مع كل push، وعلى هيئة ملف تنفيذي واحد. تأخذك أدلة التثبيت من مضيف فارغ إلى نشر عامل - openvoxserver وopenvoxdb وPostgres ووحدة التحكم - باستخدام الحاويات أو الحزم.
