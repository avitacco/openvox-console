Verbinden Sie einen KI-Agenten über MCP mit der Konsole. Er kann Ihre Flotte frei lesen. Wann immer er etwas ändern will, fragt er – und nichts läuft, bis jemand es genehmigt.

Frei lesen, vor dem Handeln fragen

Der Agent kann Nodes, Facts und Reports, Node-Gruppen, die Tasks und Pläne Ihres Codes und die Ergebnisse von Jobs ansehen. Was er sehen kann, ist genau das, was sein Token erlaubt: die Berechtigungen, die Node-Gruppen und die Tasks, die Sie beim Ausstellen gewählt haben.

Um einen Task, Puppet oder einen Plan auszuführen oder Nodes zu patchen, reicht der Agent eine Anfrage ein. Die Konsole prüft sie genau so, wie sie Ihre prüfen würde, speichert sie und teilt dem Agenten mit, dass sie wartet. Nichts hat begonnen.

The agent asks to run something The console checks it and holds it for approval A person reviews exactly what would run, and where Approved, it runs as the agent; rejected or ignored, it never does

Was Sie genehmigen, ist das, was läuft

Eine Anfrage hält den Task und seine Parameter sowie die genauen Nodes fest, auf die er wirken wird, zum Zeitpunkt der Anfrage des Agenten. Sensible Werte werden versiegelt und nie angezeigt. Die genehmigende Person sieht all das, und die Genehmigung startet genau das – nicht das, was der Agent einen Moment später verlangen könnte. Eine Anfrage, über die niemand entscheidet, läuft ab.

Der gestartete Job zeigt, dass ein KI-Agent ihn angefordert hat, welcher Agent und wer ihn genehmigt hat.

An agent token always has an expiry, is limited to the node groups and tasks you name, works only at the agent endpoint, and can be revoked at any moment. Only someone who could run the task on those nodes themselves can approve it, and never the person who issued the agent's token. Every request, approval, rejection and expiry is audited under the agent's own name, alongside the person who decided.

Der Endpunkt existiert nicht, bis Sie ihn aktivieren, und er hat eigene Ratenbegrenzungen und Größenlimits. Agenten, die kein MCP sprechen, können die dokumentierte REST-API der Konsole mit einem gewöhnlichen Token nutzen – ohne den Genehmigungsschritt, geben Sie diesen Tokens also nur, was Sie einem Skript geben würden.

So geht's

Geben Sie einem KI-Agenten ein eigenes, eingeschränktes Token, lassen Sie ihn die Flotte lesen und Änderungen anfordern, und genehmigen Sie jede Änderung selbst, bevor irgendetwas läuft.

OpenVox Console wird als Container-Images ausgeliefert, bei jedem Push für amd64 und arm64 gebaut, sowie als einzelnes Binary. Die Installationsanleitungen führen Sie vom leeren Host zu einer funktionierenden Installation – openvoxserver, openvoxdb, Postgres und die Konsole – mit Containern oder mit Paketen.
